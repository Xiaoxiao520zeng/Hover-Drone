# 硬件

保存结构、电路、接线和物料清单。每个设计应能从可编辑源文件追溯到导出件和实际装配版本。

| 内容 | 位置 |
| --- | --- |
| 结构设计、装配和加工文件 | [mechanical/](mechanical/README.md) |
| 原理图、PCB、供电与接线 | [electronics/](electronics/README.md) |
| 物料清单 | [bom.csv](bom.csv) |

提交设计时，在对应目录中写明负责人、用途、设计版本、所用软件及版本、源文件和导出文件的位置。软件参数、实验记录中的硬件版本应与这里一致。

物料清单填写器件型号、数量、规格和对应设计版本；价格、采购渠道等按需要记录。不要用压缩包代替可直接浏览的源文件目录。
