# 项目文档

| 文档 | 用途 | 何时更新 |
| --- | --- | --- |
| [项目计划](project-plan.md) | 目标、边界、验收、里程碑 | 启动时与目标变化时 |
| [成员分工](team.md) | 机械臂组、无人机组及物料清单负责人 | 人员或任务交接时 |
| [接口约定](interfaces.md) | 两组之间的机械安装、供电与控制连接 | 联调前和接口变化时 |
| [参考资料](references/README.md) | 调研、论文、数据手册的索引 | 引用新资料时 |
| [管理员设置](maintainer-setup.md) | 仓库成员、评审规则与初始化事项 | 初始化与权限调整时 |

文档正文优先使用 Markdown，便于网页阅读和评审。需要保留 Word、PDF 等文件时，附上简短说明和版本；可编辑源文件与导出版本放在同一主题目录。

具体任务、讨论结论和后续行动记录在对应 Issue 或 PR 中。两组各自的图纸、代码说明放在所属目录，公共文档在这里统一维护。
