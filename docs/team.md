# 成员与分工

项目整体只分为**机械臂部分**和**无人机部分**，各组内部自行分配具体工作。

项目统筹、需求与验收由 **Air.Zhen** 负责，全体成员参与。两组的主要负责人、接口联系人及 BOM 汇总负责人尚待指定。

| 团队 | 工作范围与资料位置 | 主要负责人 / GitHub 账号 | 组内成员 / 接口联系人 | 本组 BOM 汇总负责人 |
| --- | --- | --- | --- | --- |
| 机械臂部分 | 机械臂的设计、实现与验证；资料和代码放 [robotic-arm/](../robotic-arm/README.md)，维护 [robotic-arm/bom.csv](../robotic-arm/bom.csv) | 待指定 | 成员：待填写；接口联系人：待指定 | 待指定 |
| 无人机部分 | 无人机的设计、实现与验证；资料和代码放 [drone/](../drone/README.md)，维护 [drone/bom.csv](../drone/bom.csv) | 待指定 | 成员：待填写；接口联系人：待指定 | 待指定 |

项目计划、接口等公共资料放 [docs/](README.md)，两组实验记录统一放 [experiments/](../experiments/README.md)。这些是共享内容，不另设团队。

各组目录中的 `design/` 放设计源文件与必要导出件，`code/` 放本组代码，`bom.csv` 记录本组物料。具体工作通过组内任务分配。组内成员提供各自使用物料的信息，由本组 BOM 汇总负责人核对并维护清单；现有空表不代表已经完成统计。

## 任务与交接

- 每个 Issue 写明所属组并指定一位负责人，协作成员在描述中列出；联合任务指定一位牵头人，并列出双方参与者。
- 各组维护自己的 README，确保其他成员能找到文件、搭建所需环境并复现结果。
- 双方接口联系人共同维护[接口约定](interfaces.md)。涉及安装、承重、供电或命令反馈的改动，在 PR 中邀请另一组检查。
- 需求、联调条件与验收结论由两组共同确认，阶段目标见[项目计划](project-plan.md)。
- 交接时说明当前版本、未完成任务、已知问题和数据位置，并更新本表。

本表只记录项目协作所需的信息，联系方式放团队已有的沟通渠道。
