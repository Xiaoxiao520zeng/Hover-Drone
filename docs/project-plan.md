# 项目计划

状态：待团队填写和确认。下列里程碑是协作建议，不代表已经完成或已承诺日期。

项目由总负责人统筹，下设[机械臂组](../robotic-arm/README.md)与[无人机组](../drone/README.md)。总负责人确认总体目标和阶段计划、协调两组进度并组织联合验收；两组分别交付原型，共同确认接口、开展联调和验证。当前人员安排见[分工表](team.md)。

## 目标与边界

| 项目 | 团队确认内容 |
| --- | --- |
| 要解决的问题与应用场景 | GPS 拒止环境下，通过机械臂抓取树枝等圆柱物，使无人机悬挂停留；具体场景由团队补充 |
| 最终交付物 | 待填写，例如原型机、源代码、装配资料、实验报告 |
| 本阶段包含的功能 | 待填写 |
| 本阶段不包含的功能 | 待填写 |
| 已确认的硬件与软件平台 | 待填写；尚未选型的项目注明“待选型” |
| 预算、时间与资源约束 | 待填写 |

现有资料包括多种机体结构候选、供电与板级接线图，以及固定横杆对准与触碰联调代码。它们作为方案讨论和归档输入；采用哪个设计、哪些部分已通过实物验证，需要团队分别确认。

两组各自的设计、代码和物料清单放在本组目录，公共计划与决策放在 `docs/`，实验记录统一放在 `experiments/`。需要仿真时，再归入所属组并补充运行说明。

## 建议里程碑

| 阶段 | 应交付的内容 | 通过条件 | 日期 |
| --- | --- | --- | --- |
| M0：需求与分工 | 总负责人及两组分工、需求表、总体方案、接口约定 | 总负责人和双方联系人已确认；每项核心需求有验收方式和负责人 | 待定 |
| M1：两组原型 | 机械臂原型与无人机原型，各组设计、代码、物料及验证记录 | 两组分别完成约定检查，交付版本与未验证项目已记录 | 待定 |
| M2：联合调试 | 集成版本、安装与供电检查、抓取命令及反馈和承重流程记录 | 双方在约定条件下完成接口验证，异常与未完成事项可追踪 | 待定 |
| M3：联合验收与交付 | 联合实验报告、两组装配与运行指南、版本清单 | 总负责人组织验收，两组对照需求逐项确认，记录可供其他成员复现 | 待定 |

具体任务在 GitHub Issues 中跟踪；本页保留阶段目标，避免维护两套任务状态。

## 本周工作

在 Issues 中建立本周任务，写明机械臂组、无人机组或联合任务，并指定负责人。每项任务写清交付目录、完成标准和依赖；联合任务列出双方参与者。
