## 联调前需要确认的接口

| 接口 | 需要双方明确的内容 | 已确认约定 / 文件链接 |
| --- | --- | --- |
| 机械安装 | 安装位置、连接尺寸、紧固方式、坐标与单位、运动空间及干涉检查方式 | 待确认 |
| 质量与重心 | 两组各自交付质量、整机质量与重心基准、机械臂动作对重心的影响及允许范围 | 待确认 |
| 抓取与承重 | 适用树枝或圆柱物条件、抓取状态判定、载荷条件、承重与解除承重的流程及验证方法 | 待确认 |
| 供电连接 | 供电方、电压与电流需求、连接器及引脚、接地方式、通断电顺序和异常处理 | 待确认 |
| 抓取命令 | 命令发起方与接收方、连接方式、抓取和释放等实际所需命令、字段与单位、触发条件 | 待确认 |
| 状态反馈 | 反馈发起方与接收方、实际可测状态、反馈格式与时效要求、异常或断连的判定与处理 | 待确认 |

上述内容尚未确定的保持“待确认”，不把示例数值或推测当作约定。只在确定需要某项接口后填写具体实现；不适用的项目由双方注明理由。
