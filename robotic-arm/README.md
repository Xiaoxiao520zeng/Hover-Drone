# 机械臂组

本组负责机械臂与夹爪机构、舵机执行、微动开关及状态反馈，保存本组设计资料、代码和物料记录。

| 内容 | 位置 |
| --- | --- |
| 结构、电路、接线和装配资料 | [design/](design/README.md) |
| 控制程序、驱动和配置 | [code/](code/README.md) |
| 本组物料清单 | [bom.csv](bom.csv) |

BOM 是需求清单：“计划”为需选型的需求项，“候选”为已有资料中的参考项，“已确认”为已明确的选择；采购、库存和验收状态另行登记；数量由最终机构设计统计，不表示已有库存。

与无人机组的安装、电源、通信和动作状态约定统一记录在[组间接口](../docs/interfaces.md)。本组文档引用该约定，接口变化时同步更新。

## 当前资料与状态

已核对工作区 `rod_perching_test/README.md` 和 `switch_reader/switch_reader.ino`：既有联调原型采用前向夹口、夹口内微动开关和串口触碰反馈，触碰后请求停止接近并发送闭爪命令。这是可整理的原型路线，不代表夹爪结构、舵机或承重能力已定案。

上述原始资料与代码尚未导入本组目录。本仓库现阶段交付的是资料导航与需求清单，尚无本组实物验收结果。人员姓名与账号由成员在[分工表](../docs/team.md)登记。

## 本组交付与下一步

- 交付可编辑的机构与装配文件、必要导出件、微动开关安装及接线说明，并标明设计版本。
- 交付舵机执行与开关读取代码、环境说明、配置示例和单组验证记录；导入已有示例时保留来源与版本。
- 实测夹口几何、开关触发位置和舵机行程，核定夹持结构、执行器与供电需求，更新 [BOM](bom.csv)。
- 与无人机组共同确认安装、供电、指令和状态接口；分开验证触碰、实体闭合与承重，不能用触碰信号代替抓取成功判定。
