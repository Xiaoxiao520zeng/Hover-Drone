# 机械臂代码

保存本组舵机执行、微动开关读取、状态反馈和动作控制相关源代码及可复用配置。具体项目按需要建立子目录。

每个项目的 README 应写明：

- 功能、负责人及对应硬件设计版本。
- 开发与运行环境、工具及依赖版本。
- 构建、配置、启动或烧录方式，必要参数及单位。
- 输入输出、状态含义及异常处理方式。
- 验证步骤、预期结果和已完成的验证范围。

与无人机组交互的指令和反馈格式统一引用[组间接口](../../docs/interfaces.md)。未确定的平台与参数标为“待确认”；编译产物、缓存、个人路径和密钥不入库。

## 可整理的现有原型

工作区 `rod_perching_test/switch_reader/switch_reader.ino` 是开关读取示例：D2 使用内部上拉，低电平表示触碰，消抖时间 15 ms，USB 串口 115200，每 20 ms 输出一行 `0`（松开）或 `1`（触碰）。这些是示例默认值，尚未成为两组共同确认的接口，也未绑定具体 MCU 板型。

工作区原型 README 还约定通过 ArduPilot Gripper 1 发起闭爪。该控制路径依赖无人机组所用飞控固件及接口适配；不能因为收到命令 ACK 就认定实体闭合或承重成功。

板端供电、信号和开关示例集中见[板卡接口登记](../../drone/design/board-interfaces.md)。MCU 型号尚未确定，示例 D2 不等于 X25 或 Jetson 的针脚；Gripper 1 也不等于物理 PWM M1，具体输出通道需要单独分配。

## 代码交付与验证

- 将拟采用的开关示例整理为本组可构建项目，登记板型、工具版本、引脚和烧录方式。
- 提供舵机控制配置及开合行程说明，明确命令、真实可测状态和异常反馈；具体实现由两组确认后定版。
- 记录松开、触碰、反复触发和断开连接时的输出，核对消抖与上报行为；闭合和承重另外记录实物验证。

原始示例尚未导入本目录，当前不存在已登记的构建或实物通过结果。下一步先完成 MCU 与舵机设备登记，再提交代码与对应验证记录。
