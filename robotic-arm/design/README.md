# 机械臂设计资料

保存机械臂与夹爪结构、舵机安装与执行关系、微动开关布置、接线及装配说明。具体设计按需要建立子目录。

每项设计保留可编辑源文件、必要导出件，并说明负责人、设计版本、软件及版本、尺寸单位和装配关系。接线资料写明接口名称、引脚、信号方向和电气参数；未确定的内容标为“待确认”。

与无人机组的连接和状态约定引用[组间接口](../../docs/interfaces.md)。修改设计时，同步更新本组物料清单和受影响的代码说明。

## 已知依据与适用范围

工作区 `rod_perching_test/README.md` 描述的原型为“机头夹口朝前、虎口内装微动开关”。`switch_reader/switch_reader.ino` 给出常开触点读取示例：COM 接 GND，NO 接 D2，使用内部上拉。此接法只描述该示例，具体 MCU 引脚、电平、连接器和布线仍需按实物核定。

本次核对资料未提供可作为本组定版依据的夹爪制造图、舵机选型或承重验收报告；不据此填写已经验证的结构参数。

## 需要形成的设计交付

- 机构源文件与必要导出件：夹口尺寸、运动范围、舵机与开关安装、紧固及装配关系。
- 电路和接线说明：舵机供电需求、MCU 与开关接口、连接器和线束固定方式。
- 安装与验证记录：与机体连接的尺寸、质量与重心数据、触发位置、开合行程、夹持与承重验证条件。

下一步先核定试验横杆与夹口几何，再检查触碰时的开关动作、实体闭合及视觉可见性，最后按双方确认的条件进行承重验证。每项结果注明设计版本、日期和记录位置；当前实物验证状态为“未在本仓库登记”。
