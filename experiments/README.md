# 实验记录

保存可复现的实验方案、参数、过程、结果和结论。一次实验或同一目标的一组实验建立独立目录，例如 `YYYY-MM-DD_topic/`；目录内使用 [TEMPLATE.md](TEMPLATE.md) 编写 `README.md`。

记录至少包含日期、负责人、目标、硬件版本、完整 Git 提交、环境、参数、步骤、结果和数据位置。未完成的字段写“待填写”；尚未做过的验证明确写“未验证”。

必要的小型结果图、汇总表可随记录入库。原始日志、长视频、模型权重和大型数据集放在团队约定的存储位置，记录可访问的链接、文件标识及获取方法，避免重复提交压缩包。

实验失败也保留当时配置、现象和结论；后续修正通过新记录或明确标注的补充说明关联，方便比较。
