# 无人机组

本组负责机体与机械臂搭载、飞控配置、机载视觉、目标对准及飞行任务衔接，保存本组设计资料、代码和物料记录。

| 内容 | 位置 |
| --- | --- |
| 机体结构、搭载、电路和接线资料 | [design/](design/README.md) |
| 飞控配置、机载程序及任务代码 | [code/](code/README.md) |
| 本组物料清单 | [bom.csv](bom.csv) |

BOM 是需求清单：“计划”为需选型的需求项，“候选”为已有资料中的参考项，“已确认”为已明确的选择；采购、库存和验收状态另行登记；数量为设计需求，X25 Evo 和 Jetson Orin 各按单机 1 套规划，不表示已有库存。

与机械臂组的安装、电源、通信和动作状态约定统一记录在[组间接口](../docs/interfaces.md)。本组文档引用该约定，接口变化时同步更新。

## 当前平台与资料状态

项目已确定 **X25 Evo 飞控**与 **Jetson Orin 机载计算平台**。Orin 的具体子型号、载板、JetPack 和系统版本需要登记；指定硬件不等于已经确认其固件与现有程序兼容。

[X25 EVO 官方说明](https://doc.cuav.net/controller/x25-evo/)列出 ArduPilot 与 PX4 支持；团队需记录实机实际采用的固件。Orin 的设备登记可对照 [Jetson Orin 产品家族](https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/jetson-orin/)及 [JetPack](https://developer.nvidia.com/embedded/jetpack)资料。

已核对的工作区资料有两类，原始文件尚未导入本组目录：

- `树枝无人机_Jetson立装窄板_STL/` 的装配、模块尺寸及接线说明：用于尺寸与走线核对的候选结构资料，动力和电源组合仍需实物验证。
- `rod_perching_test/`：基于 OAK-D Pro 的固定横杆红色标记对准与触碰联调原型；OAK-D Pro 是既有原型依赖，整机采用尚待确认。其飞控接口针对 ArduCopter GUIDED，需在指定飞控上验证适配。

## 本组交付与下一步

- 登记飞控实机固件与版本、Orin 完整型号和软件环境，确认连接与外部定位条件。
- 整理机体、搭载和供电设计，提交源文件、必要导出件、接线说明与 [BOM](bom.csv)。
- 整理机载程序及参数说明，形成视觉、目标对准、触碰停进与闭爪任务的接口和验证记录。
- 先确认设备与台架接口，再按共同确认的条件推进定位和联合实验；闭爪之后的停桨、载荷转移与持续停栖需要单独设计和验证。

本仓库尚未登记整机飞行或挂接通过结果。人员姓名与账号由成员在[分工表](../docs/team.md)填写。
