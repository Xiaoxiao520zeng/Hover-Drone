# 无人机设计资料

保存机体结构、机械臂搭载关系、设备安装、电路、供电和接线说明。具体设计按需要建立子目录。

每项设计保留可编辑源文件、必要导出件，并说明负责人、设计版本、软件及版本、尺寸单位和装配关系。接线资料写明接口名称、引脚、信号方向和电气参数；未确定的内容标为“待确认”。

与机械臂组的安装、电源和通信约定引用[组间接口](../../docs/interfaces.md)。修改设计时，同步更新本组物料清单和受影响的代码说明。

## 设计交付与下一步验证

- 先登记实际设备尺寸、质量、孔位和接头方向，再更新搭载设计、线束路径及物料清单。
- 交付可编辑机体与搭载模型、必要导出件、装配说明、供电与信号连接图，并明确设计版本。
- 与机械臂组核对安装、运动与相机视野，记录相机到触发点的实际偏移和安装角；装配模型坐标与程序机体坐标需明确转换。
- 记录装配干涉、质量与重心、供电、散热和动力验证结果；原图桨型存在需要确认的具体型号，不将参考组合视为最终动力方案。
